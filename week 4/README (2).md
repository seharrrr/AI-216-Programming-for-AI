# Python Data Structures Project

## Project Overview

This project demonstrates the use of basic Python data structures including:

* Lists
* Tuples
* Sets
* Dictionaries
* Nested Dictionaries
* Loops and Conditions

The notebook contains multiple small programs for practicing data handling and analysis in Python.

---

# Features

## 1. Product Price Analysis

* Calculates total number of products
* Finds average price
* Displays products above 2000
* Sorts prices in descending order

### Concepts Used

* Lists
* Loops
* Conditions
* Sorting

---

## 2. Location Coordinate Processing

* Stores latitude and longitude values
* Extracts latitudes
* Counts total coordinate pairs

### Concepts Used

* Tuples
* Lists
* Loops

---

## 3. Student Course Management

* Finds students enrolled in both courses
* Finds students only in Python course
* Creates a master student set
* Removes a student from ML course

### Concepts Used

* Sets
* Intersection
* Union
* Difference

---

## 4. Employee Management System

* Stores employee records
* Displays employee IDs
* Finds employees earning above 60000
* Adds new employee records

### Concepts Used

* Dictionaries
* Nested Dictionaries
* Loops

---

## 5. Sales Revenue Report

* Calculates category-wise revenue
* Stores unique product names
* Displays sales report

### Concepts Used

* Nested Data Structures
* Dictionaries
* Sets
* Loops

---

# Technologies Used

* Python 3
* Google Colab / Jupyter Notebook

# How to Run the Project

1. Install Python 3
2. Open the notebook in:

   * Google Colab
   * Jupyter Notebook
   * VS Code
3. Run each code cell one by one
